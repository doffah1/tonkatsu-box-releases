# Tonkatsu Box — descargas

Solo contiene los instaladores publicados de una versión personal de
[Tonkatsu Box](https://github.com/hacan359/tonkatsu_box) (licencia MIT, copyright (c) 2025 hacan359).
La app los usa para actualizarse desde Ajustes → Actualizaciones.

- Windows: `tonkatsu_box-windows-x64.zip`
- Android: `tonkatsu_box-android-arm64-v8a.apk` (la mayoría de móviles)
